# Keyboard Shortcuts

## General

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd+Z` | Undo |
| `Ctrl/Cmd+Y` / `Ctrl/Cmd+Shift+Z` | Redo |
| `Ctrl/Cmd+A` | Select all frames and text on current spread |
| `Delete` / `Backspace` | Delete selected element(s) |
| `Escape` | Deselect all / exit current tool / exit inline text edit |

## Spreads

| Shortcut | Action |
|----------|--------|
| `N` | Add a new spread after the current one |
| `←` / `↑` | Previous spread |
| `→` / `↓` | Next spread |

## Canvas navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd` + scroll wheel | Zoom toward cursor |
| `Ctrl/Cmd++` / `Ctrl/Cmd+=` | Zoom in |
| `Ctrl/Cmd+-` | Zoom out |
| `Ctrl/Cmd+0` | Reset zoom to 100% |
| `Space` + left drag | Pan canvas |
| Middle mouse button drag | Pan canvas |

## Tools

| Shortcut | Action |
|----------|--------|
| `K` | Toggle cut (frame splitting) tool |
| `T` | Enter text placement mode |

## Selection

| Shortcut | Action |
|----------|--------|
| `Click` | Select element |
| `Ctrl/Cmd+Click` | Toggle element in/out of multi-selection |
| `Shift+Click` | Extend selection range |
| `Shift+Drag` on empty canvas | Marquee — select all elements inside rectangle |
| `Click` on empty canvas | Deselect all |

## Modifiers

| Modifier | Effect |
|----------|--------|
| `Alt` (during divider drag or cut tool) | Disable snapping — position freely |

## Image adjustments (on canvas)

| Shortcut | Action |
|----------|--------|
| Scroll wheel over frame | Scale image in/out |
| `Shift` + scroll wheel over frame | Rotate image (±0.5° per step) |
| Drag inside frame | Pan image within frame |
| `Alt` + drag from frame to frame | Swap images between two frames |

## Text editing

| Shortcut | Action |
|----------|--------|
| `Double-click` | Enter inline edit mode |
| `Escape` | Exit inline edit mode |
