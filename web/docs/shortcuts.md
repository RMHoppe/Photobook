# Keyboard Shortcuts

## Canvas

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo |
| `Ctrl+A` | Select all elements |
| `Delete` / `Backspace` | Delete selected element |
| `Escape` | Deselect / exit tool / exit inline text editing |
| `Ctrl++` / `Ctrl+-` | Zoom in / zoom out |
| `Ctrl+0` | Reset zoom to 100% |
| `Arrow keys` | Navigate selection to adjacent frame |

## Tools

| Shortcut | Action |
|----------|--------|
| `K` | Toggle cut tool |
| `T` | Enter text placement mode |

## Selection

| Shortcut | Action |
|----------|--------|
| `Click` | Select element |
| `Shift+Click` | Add to / remove from selection |
| `Cmd+Click` / `Ctrl+Click` | Toggle element without clearing other selections |
| `Click` on empty area | Deselect all |

## Text editing

| Shortcut | Action |
|----------|--------|
| `Double-click` | Enter inline edit mode |
| `Escape` | Exit inline edit mode |
| `Ctrl+A` | Select all text in element |
| `Ctrl+C` / `Ctrl+V` | Copy / paste |
