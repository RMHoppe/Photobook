## Zooming

| Method | Action |
|--------|--------|
| `Ctrl/Cmd` + scroll wheel | Zoom toward the cursor position |
| `Ctrl/Cmd` + `+` | Zoom in by 25% |
| `Ctrl/Cmd` + `-` | Zoom out by 25% |
| `Ctrl/Cmd` + `0` | Reset zoom to 100% and centre the canvas |
| Zoom buttons (bottom-right) | Same as keyboard shortcuts |

The zoom range is 50%–500%.

## Panning

Move the canvas by holding **Space** and dragging with the left mouse button — the cursor becomes a hand. You can also pan with the **middle mouse button** at any time without pressing Space.

## Fullscreen preview

Click the **expand icon** in the bottom-right corner of the canvas to open a fullscreen preview of the current spread. The preview hides all UI chrome and overlay guides (bleed, safe zone) so you can judge the design as it will appear in print.

- Navigate between spreads with the **← / →** buttons or the arrow keys.
- Press **Escape** to close the preview.
