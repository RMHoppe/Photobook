## Adding text

Click **+ Text** in the toolbar, then click on the canvas where you want the text to appear. A text element is created at that position.

## Editing text

Double-click a text element to enter inline editing mode. A cursor appears and you can type or paste text. Click outside the element or press **Escape** to finish editing.

## Text properties

With a text element selected, the right sidebar shows:

| Property | Description |
|----------|-------------|
| Font family | Choose from the fonts loaded from your system |
| Font size | Size in points |
| Bold / Italic | Toggle weight and style |
| Colour | Text colour picker |
| Alignment | Left, centre, or right |
| X / Y | Position in mm |
| Rotation | Rotation in degrees |

## Deleting text

Select the text element and press **Delete** or **Backspace** (when not in inline edit mode).
