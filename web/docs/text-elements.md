## Adding text

Press **T** (or click **+ Text** in the toolbar) to enter text placement mode — the cursor changes to a crosshair. Click anywhere on the canvas to place a new text element at that position. The element is created and immediately shown in the sidebar for styling.

Press **Escape** to exit placement mode without creating a text element.

## Editing text

**Double-click** a text element to enter inline editing mode. A cursor appears and you can type, paste, or delete text. The element supports multiple lines. Click outside the element or press **Escape** to finish editing.

## Moving and resizing text

| Interaction | Result |
|-------------|--------|
| Click and drag the text body | Move the element to a new position |
| Drag a corner handle | Scale the font size proportionally |

Corner handles appear when the element is selected. Drag any corner outward to make the text larger, inward to make it smaller. The minimum font size is 1 pt.

## Rotating text

A circular rotation handle appears above the selected text element. Drag it to rotate the element to any angle. The rotation value is also editable directly in the sidebar.

## Text properties

With a text element selected, the right sidebar shows:

| Property | Description |
|----------|-------------|
| Font family | Choose from system fonts (click **Load System Fonts** to query installed fonts) |
| Font size | Size in points (4–300 pt) |
| Bold | Toggle bold weight |
| Italic | Toggle italic style |
| Underline | Toggle underline decoration |
| Colour | Text colour picker |
| Alignment | Left, centre, or right |
| X / Y | Position in millimetres on the spread |
| Rotation | Rotation in degrees |

## Selecting multiple text elements

Ctrl/Cmd + Click to add text elements to a selection. When multiple text elements are selected, editing a property in the sidebar applies it to all of them. Fields that differ across the selection show a "mixed" placeholder.

## Deleting text

Select a text element and press **Delete** or **Backspace** (when not in inline edit mode).
