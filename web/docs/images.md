## Opening a folder

Click **Open Folder** in the left sidebar. All images in the selected folder are shown as thumbnails. Sub-folders are not traversed.

## Placing images

Drag a thumbnail from the left sidebar and drop it onto an empty frame on the canvas. The image is scaled to fill the frame while preserving its aspect ratio (cover fit).

You can also drag an image onto an already-filled frame to replace it.

## Replacing an image

Drag a new image from the sidebar onto an existing frame. The old image is replaced immediately. The frame dimensions do not change.

## Supported formats

| Format | Notes |
|--------|-------|
| JPEG | Full support |
| PNG  | Full support, transparency rendered on white |
| WebP | Supported in modern browsers |
