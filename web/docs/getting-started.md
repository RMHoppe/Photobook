# Getting Started

Photobook is a browser-based editor for designing print-ready photo books. It runs entirely in the browser — no account or upload required.

## Table of Contents

- [Opening a folder](#opening-a-folder)
- [The workspace](#the-workspace)
- [Basic workflow](#basic-workflow)

## Opening a folder

Click **Open Folder** in the left sidebar to select a folder of images from your local drive. The images appear as thumbnails in the image browser.

> The folder is opened read-only. Photobook never modifies your original files.

## The workspace

The workspace has three areas:

| Area | Purpose |
|------|---------|
| **Left sidebar** | Image browser — drag images onto the canvas |
| **Canvas** | The current spread, shown at the selected zoom level |
| **Right sidebar** | Properties for the selected frame, or project-wide settings |

Use the **footer** at the bottom to switch between spreads and view thumbnails.

## Basic workflow

1. Open a folder of images.
2. Add a spread with **+ Spread**.
3. Drag images from the sidebar onto the canvas to fill frames.
4. Adjust frame position and size using the right-sidebar controls.
5. Add text with **+ Text** and style it in the sidebar.
6. Export to PDF when finished.
