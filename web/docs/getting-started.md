# Getting Started

Photobook is a browser-based editor for designing print-ready photo books. It runs entirely in the browser — no account, no upload, no installation required.

## The workspace

| Area | Purpose |
|------|---------|
| **Toolbar** (top) | Global actions: save/load, undo/redo, add text, cut tool, export PDF, project settings, help |
| **Left sidebar** | Image browser — open a folder and drag photos onto the canvas |
| **Canvas** (centre) | The current spread at the selected zoom level |
| **Right sidebar** | Properties for the selected frame, text, or divider; spread settings when nothing is selected |
| **Footer** (bottom) | Thumbnail strip for all spreads; add / remove spreads; navigate between them |

> The editor is designed for desktop use. A minimum screen width of 1024 px is required.

## Your first book

1. **Open a folder** — click **Open Folder** in the left sidebar and select a folder of images. Thumbnails appear immediately.
2. **Set the page size** — click the **Project Settings** gear icon in the toolbar and choose a page size (or leave the default).
3. **Add spreads** — click **+ Spread** in the footer (or press **N**) to add pages to your book.
4. **Split frames** — press **K** to activate the Cut tool, then click on a frame to split it into two. Click more times to create more frames. Press **Escape** when done.
5. **Place images** — drag thumbnails from the left sidebar onto frames. Drop on the centre to fill a frame; drop on an edge to split it and fill the new half simultaneously.
6. **Add text** — press **T** (or click **+ Text**), then click on the canvas to place a text element. Select it to edit font, size, and colour in the right sidebar.
7. **Navigate** — use the footer arrows or press **← →** to move between spreads.
8. **Export** — click **Export PDF** in the toolbar when you are happy with the layout.

## Undo and redo

Every action is recorded. Press **Ctrl+Z** (Mac: **Cmd+Z**) to undo and **Ctrl+Y** (or **Ctrl+Shift+Z**) to redo. The undo/redo buttons in the toolbar are disabled when there is nothing to undo or redo.
